# JS MCQ Admin

React/Vite administrator interface for the JS MCQ API.

## Local setup

1. Configure and start the API using the instructions in [../backend/README.md](../backend/README.md).
2. Install and start this app from the repository root:

   ```powershell
   npm install --prefix admin
   npm run dev --prefix admin
   ```

3. Open `http://localhost:5174` and sign in, or choose **Request access** to register an account for an existing administrator to approve.

The development server proxies `/api` to `http://localhost:3000`. The backend `ADMIN_ORIGIN` must allow `http://localhost:5174`. For another API host, set `VITE_API_BASE_URL` when building/deploying the app.

## Included

- **Sign-in:** admin login, session restore and logout using the API's HttpOnly cookie.
- **Request access:** a registration screen linked from sign-in. New accounts are inactive until approved.
- **Administrators:** approve or reject pending registrations, and deactivate, reactivate or delete other administrators. A badge in the sidebar shows how many requests are waiting.
- **Overview:** counts of technologies, sections, topics, questions and questions with resource links, plus content per technology and recently updated questions.
- **Content structure:** three columns (Technologies › Sections › Topics) with create, edit and delete in dialogs. Slugs are generated by the API from the name. Sections take an optional membership URL; topics take an optional Medium article URL and a premium (`isPaid`) switch. Topics can be dragged into display order.
- **Question library:** search and technology › section › topic filters. Pick a topic and clear the search to drag questions into display order (arrow buttons work from the keyboard).
- **Question editor:** full-page editor with placement pickers, label, text/code/JSON prompt blocks (code can be formatted), answer, Medium and compiler links, and a premium switch.
- **Confirmations:** deletes use one app-wide confirmation dialog (`ConfirmProvider` / `useConfirm()` in `src/components/ConfirmProvider.jsx`). Items that still contain content explain what to remove first instead of failing.
- **Themes:** light and dark, following the system setting until toggled.

New content is immediately available in the public learner app; turn `isActive` off on a technology, section or topic to hide it.
